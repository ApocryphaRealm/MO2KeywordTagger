# Third-party notices - MO2 [NoDelete] Tag Generator

## Inspiration

The idea - a [NoDelete] tag carrying an index so Wabbajack keeps a user's own mods in their own order - comes from
**Wabbajack NoDelete Automatic Indexer plugin for MO2** by Alfthebigheaded
(https://www.nexusmods.com/site/mods/669). This plugin shares no code with it; it is a different take on the same
job (one dialog, the NoDelete separator, one on-disk rename pass), written from scratch.

## Wabbajack logo (toolbar icon)

`MO2NoDeleteTagGenerator.png` is a single-colour silhouette of the Wabbajack logo (`Branding/PNGs/Logo_Transparent.png` in
https://github.com/wabbajack-tools/wabbajack, GPL-3.0). It marks the button that produces Wabbajack's own `[NoDelete]`
convention. Wabbajack is a project of the Wabbajack team; this plugin is not affiliated with it.

## Mod Organizer 2

The plugin runs on the Mod Organizer 2 Python plugin API (https://github.com/ModOrganizer2/modorganizer, GPL-3.0).
